# 量枢 MetriX — 产品设计

> 本地优先的参数管理系统 · Tauri 桌面客户端 · v1

## 1. 产品定位

把散落的配置、凭据、素材统一收进「参数笔记」，一次录入、随处取用。
通用笔记形态（图片/文本/文件混排）+ 凭据安全增强（默认打码、一键复制）。
纯本地、明文存储 SQLite，离线可用，无账号无同步。

## 2. 核心概念模型

```
文件夹 Folder ──┬── 参数笔记 Note ── 参数项 Item（6 种类型）
标签 Tag ──────┘      ├─ 名字（必填）
                      ├─ 收藏 / 敏感标记
                      └─ 备注、创建/更新时间
```

参数项统一结构：`标题 + 类型 + 内容 + 备注(meta) + 排序 + 时间戳`。
图片/文件内容存 `blobs` 表（BLOB 列，单个 ≤ 20MB），items.meta 存 `{blobId, name, mime, size}`。

| 类型 | 标题含义 | 内容 | 特殊交互 |
|---|---|---|---|
| kv 键值对 | 参数名 key | value | 行内编辑、单值复制 |
| image 图片 | — | blob | 拖拽/粘贴、缩略图、点击预览、另存为 |
| text 文本 | 标题 | 多行文本 | 自适应高度、复制 |
| secret 密钥 | 用途名 | 敏感串 | 默认 ••••、眼睛切换、复制、不参与全文搜索 |
| file 文件 | — | blob | 大小/类型、双击打开、另存为 |
| url 链接 | 链接名 | 地址 | 卡片化、浏览器打开、复制 |

## 3. 信息架构（三栏）

- **左栏**：全部笔记 / 收藏 / 最近编辑、文件夹树（嵌套、新建/重命名/删除、拖拽移动、笔记拖入归档）、标签筛选
- **中栏**：当前范围笔记列表（名字、文件夹、标签、项数、相对时间）；笔记可拖入左栏文件夹
- **右栏**：笔记详情——阅读态为主，字段行内点击即编辑、失焦自动保存；参数项卡片流支持拖拽排序；底部常驻「＋添加参数」；空状态提供 6 宫格快捷入口

**全局搜索** `⌘K`：搜笔记名、标签、参数标题、文本内容、URL；**secret 的 value 不进索引**。

## 4. 关键流程

### 新建笔记
「＋」或 `⌘N` → 输入名字（可选文件夹/标签）→ 进入空详情页 → 空状态 6 宫格选类型 → 行内填内容即落库。

### 添加参数
详情页底部「＋添加参数」→ 6 宫格类型选择 → 列表末尾插入新卡片。

### 高频操作
- 复制：值旁 📋，复制后 ✔ 反馈（KV/文本/密钥/URL）
- 密钥：默认打码，眼睛切换或聚焦输入框揭示；整篇「敏感」开关
- 图片：`⌘V` 粘贴截图；文件：从系统拖入（Tauri drag-drop 事件 → 读取 → 入库），超 20MB 拒绝
- 删除：卡片悬停垃圾桶 → 确认删除；笔记删除需二次确认

## 5. 数据模型（SQLite 明文）

```sql
folders(id, name, parent_id, sort)
notes(id, name, folder_id, favorite, sensitive, created_at, updated_at)
tags(id, name UNIQUE)
note_tags(note_id, tag_id)
items(id, note_id, type, title, content, meta JSON, sort, created_at, updated_at)
-- type ∈ kv|image|text|secret|file|url
blobs(id, name, mime, size, data BLOB)
```

- 外键开启、WAL 模式；`app_data_dir/metrix.db`
- 全文搜索用 LIKE（对中文更可靠；个人规模数据量下性能足够）
- 删除笔记/参数项时级联清理 blobs

## 6. 版本范围

**v1（已实现）**：三栏布局、文件夹+标签双轨、6 类型参数 CRUD、拖拽排序、行内编辑自动保存、打码与一键复制、全局搜索、收藏/最近、敏感笔记、图片粘贴与文件拖拽（20MB）、文件另存为/打开。

**延后（v1.1+）**：导入/导出（JSON + blobs zip）、主密码加密库、多环境快照切换、历史版本、云同步、自动填充、剪贴板自动清理。
